# MNIST-notebook
This study applies **neural networks to handwritten digit classification** using the MNIST dataset. The objective is to evaluate how different training strategies and network architectures affect classification accuracy and learning efficiency.The analysis provides a progressive comparison of neural networks by modifying epochs, batch size, hidden layers, neurons and activation functions.
The dataset contains **70,000 grayscale images representing digits 0–9**, with each image having **28 × 28 pixels**. The data is split into training, validation and test sets, normalized to the 0–1 range and reshaped into 784 input features. The ten output classes are converted into one-hot encoded vectors. A baseline network is then followed by several models with different architectural and training configurations.
The baseline network achieves **approximately 15% accuracy with 10 epochs**. Increasing the number of epochs improves accuracy but requires additional training time. Using smaller batches enables more frequent parameter updates and considerably improves learning. The addition of hidden layers further improves performance, while experiments with activation functions show that tanh and ReLU generally outperform sigmoid in the tested models.
The later architectures achieve approximately **97–98% validation accuracy**. Increasing the training period to 100 epochs produces 100% training accuracy, but validation accuracy remains within a similar range, suggesting that additional training provides limited generalization benefits. Overall, the analysis demonstrates that effective neural network performance depends on **appropriate combinations of architecture, batch size, activation function and training duration** rather than simply increasing model complexity.
